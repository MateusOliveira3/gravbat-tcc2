# Consolidação V1.0 — escopo e verificação

## Estado do conjunto

O dashboard reúne o modelo mecânico, transmissão, carga mecânica, prévia eletromecânica, ciclo de descida-subida, dimensionamento preliminar e comparação de cenários.

## O que a V1.0 permite afirmar

O modelo permite calcular e comparar cenários sob hipóteses explícitas de geometria, massa, eficiência, parâmetros eletromecânicos e potência de recarga. Ele permite investigar energia, potência, tempo, perdas e saldo líquido de ciclo em ordem de grandeza.

## O que a V1.0 ainda não permite afirmar

Não há identificação experimental do motor, validação de uma instalação real, projeto estrutural do cabo, controle detalhado, custo, disponibilidade de terreno ou comprovação de atendimento a uma casa/cidade. Os resultados permanecem calculados ou simulados.

## Verificação final

Devem ser executados os testes automatizados, compilação dos módulos e verificação do dashboard. A consolidação só é considerada reproduzível quando os comandos do README forem executados sem alteração manual do código.
