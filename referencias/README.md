# Biblioteca científica do GravBat

Esta pasta reúne referências para a auditoria científica E1–E5 e para a comparação entre arquiteturas gravitacionais verticais e inclinadas.

## Critérios

- Um registro no catálogo não significa que o artigo foi lido integralmente.
- PDFs só serão armazenados quando houver acesso legal e permissão de redistribuição identificável.
- Cada fichamento classifica a fonte como `TEXTO_INTEGRAL`, `RESUMO` ou `METADADOS`.
- Números, equações e páginas não são transcritos sem fonte verificável.
- As referências não validam experimentalmente o GravBat; servem para fundamentação e comparação.

## Organização

- `01_vertical`: arquiteturas verticais, poços e massas suspensas.
- `02_inclinado`: trilhos, rampas, montanhas e sistemas ferroviários gravitacionais.
- `03_modelagem`: dinâmica, perdas, transmissão e conversão.
- `04_revisoes`: revisões de armazenamento gravitacional.
- `05_aplicacoes`: integração com renováveis e cenários de sistema.
- `06_maquinas_controle`: geradores, retificação e controle, a complementar.
- `fichamentos`: leitura crítica rastreável.

O estado de acesso e o hash SHA-256 dos PDFs, quando houver, ficam no `catalogo.csv`.
